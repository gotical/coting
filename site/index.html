Coding-агент
для смартфонов

Coting (Котинк) — автономный ИИ-агент для кодинга и системного администрирования, созданный исключительно для телефонов. Пишет и правит код, выполняет команды, лазает по интернету, управляет самим смартфоном и твоими серверами по SSH — целиком локально, в Termux.

Три формы — один кот 🐾

Работай как удобно: чистый терминал, браузер или нативное приложение. Всё — один и тот же агент на 127.0.0.1.

без APK

📟 CLI в Termux

Установка одной командой curl … | bash. Управление: coting start / web / status, провайдеры: coting provider list / add / test. Сервер, чат и весь агент живут в терминале телефона — приложение не требуется.

PWA

🌐 Веб-интерфейс

Команда coting web открывает чат в стиле ChatGPT: стриминг ответов, спойлер размышлений, вложения, история с поиском, светлая/тёмная тема. Можно добавить на главный экран как PWA.

Что умеет кот

9 инструментов агента, мульти-провайдер и приватность по умолчанию.

Shell, файлы, кодВыполняет команды, читает/пишет/правит файлы, ищет по проекту ripgrep'ом. Полноценный кодинг в папке проекта.
Серверы SSH / SFTP / FTP«Проверь диск на моём VPS», «залей build на хостинг» — агент подключается к аккаунтам из настроек и делает.
Управляет телефономТапы, свайпы, чтение текста экрана, скриншоты, системные кнопки, блокировка — с твоего явного согласия.
Лазает по интернетуweb_fetch изучает страницы и API (под UA мобильного Яндекс.Браузера). Статус «изучаю example.com…» виден в чате.
МультимодальностьПрикрепи картинку или файл: «сделай сайт как на макете», «составь договор по образцу». Ответы с diff-подсветкой правок.
Мульти-провайдерz.ai, Alibaba, Gemini-прокси, TokenWave + любой свой Anthropic/OpenAI-совместимый API. Выбор модели в один тап.
БезопасностьВсё на 127.0.0.1, ключи не покидают устройство, подтверждение shell-команд, скрытых режимов нет.
История и поискВсе чаты сохраняются и переживают рестарты; поиск по содержимому найдёт тот разговор про nginx.
ЭкспортПроект — ZIP'ом в Download, картинки из чата — в один тап, код — кнопкой «копировать».

Установка

Нужен только Termux. Всё остальное — одна команда.

1

Termux (официальный)

Скачай Termux из F-Droid — не из Play Маркет (устаревшая сборка).

📲 f-droid.org/packages/com.termux ↗
2

Одна команда — и всё

Вставь в Termux: поставит nodejs/ripgrep, скачает сервер, пропишет доступы, запустит чат.

curl -fsSL https://raw.githubusercontent.com/gotical/coting/main/install.sh | bash
coting web — открыть чат в браузере
coting start · stop · status — сервер
coting provider list — модели
3

APK (по желанию)

Для кнопки «поднять сервер», управления телефоном, скриншотов и галереи. Работает и без приложения — через веб.
