# 🐱 Coting (Котинк)

**Кодинг-агент и системный администратор с ИИ — созданный исключительно для смартфонов.**

Полноценный автономный агент, который целиком живёт в твоём телефоне: пишет и правит код,
выполняет команды, лазает по интернету, управляет самим телефоном и твоими серверами —
через приятный чат в стиле ChatGPT.

## 📱 Три формы — один кот

| | Что это | Для кого |
|---|---|---|
| 🧩 **APK** | Приложение: чат + кнопка «поднять сервер» + управление телефоном | Основной способ |
| 🌐 **Веб** | Чат `127.0.0.1:8395` в браузере или PWA на главный экран | Для тонкой настройки |
| 📟 **Termux CLI** | `coting` — управление, `coting provider` — аккаунты | Для терминал-людей |

## ✨ Возможности

- 🤖 **Настоящий агент**: 9 инструментов — shell, чтение/запись/правка файлов, поиск по коду, интернет (`web_fetch` под UA Яндекс.Браузера), **управление телефоном** (тапы, свайпы, чтение экрана, скриншоты, блокировка экрана), **твои серверы по SSH/SFTP/FTP** — «проверь диск на моём VPS» из чата.
- 📎 **Мультимодальность**: прикрепи картинку или файл в чат — «сделай сайт как на изображении», «составь договор по образцу из этого txt/pdf».
- 💭 **Размышления-спойлер**: поток мыслей модели («кот думает») виден в чате и раскрывается по тапу.
- 📡 **Статусы как у больших агентов**: «выполняет: `ls -la`…», «лазает по интернету: example.com…», «правит `index.html`» — по нажатию видно, какую команду выполнил, какой сайт изучил и **что удалил и что добавил** (diff красным/зелёным).
- 🔄 **Мульти-провайдер**: встроенные тарифы (zai / alibaba / gemini / tokenwave) + **любой свой API** — Anthropic- или OpenAI-совместимый. Ключи не покидают устройство.
- 💬 **История чатов с поиском** по содержимому — вернись к любой задаче в любом проекте.
- 📦 **Скачать проект ZIP'ом** прямо в Download телефона; картинки из чата сохраняются в один тап; код из ответов — кнопкой «копировать».
- 🌗 **Светлая и тёмная темы**, PWA «на главный экран», стриминг ответа в реальном времени.
- 🔒 **Безопасность**: всё на `127.0.0.1`, ключи только локально, опциональное подтверждение shell-команд (approval-флоу), accessibility/admin включаются владельцем вручную — скрытых режимов нет.

## 🚀 Установка в Termux — одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/gotical/coting/main/install.sh | bash
```

Скрипт поставит зависимости (nodejs, ripgrep), скачает сервер и запустит чат. Дальше:

| команда | что делает |
|---|---|
| `coting web` | открыть чат в браузере сразу |
| `coting start` / `stop` / `restart` / `status` | управление сервером |
| `coting provider list` | провайдеры и модели |
| `coting provider add <id> <baseUrl> <anthropic\|openai> <apiKey> <модели> [имя]` | свой аккаунт |
| `coting provider test <id>` | проверка ключа |

## 📲 Android-приложение (быстрая ссылка)

**[📥 Скачать APK →](https://github.com/gotical/coting/releases/latest/download/coting.apk)**

Открой → кнопка «🐾 Запустить сервер в Termux» поднимет всё сама (нужен установленный Termux
с Coting). В приложении же:

- **📖 Инструкция** — установка в чистый Termux одной командой (копируется в буфер) + кнопка скачивания Termux;
- **Управление телефоном** (Accessibility) — жесты, чтение экрана, скриншоты; включается владельцем вручную;
- **🔒 Права администратора** — блокировка экрана по команде из чата (только force-lock);
- доступ к **галерее и файлам** — прикрепляй изображения и документы прямо в чат.

## 🧰 Сборка APK из исходников (Termux, без Gradle)

```bash
git clone https://github.com/gotical/coting && cd coting/android
keytool -genkeypair -v -keystore keystore.jks -alias key -keyalg RSA -keysize 2048 -validity 10000 -storepass android
./build.sh && su -c "pm install -r coting.apk"   # или adb install -r coting.apk
```
